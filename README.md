# 📣 AI Marketing Attribution

[![Models](https://img.shields.io/badge/Attribution%20Models-8-blue)](.) [![ROAS](https://img.shields.io/badge/ROAS%20Improvement-%2B34%25-green)](.) [![Budget](https://img.shields.io/badge/Budget%20Optimized-R%2448M%2Fyear-orange)](.)

> **AI marketing measurement** combining multi-touch attribution, Media Mix Modeling (LightweightMMM) and causal incrementality testing. Optimized **R$48M/year** ad budget, achieving **+34% ROAS improvement**.

## 🏗️ Attribution Stack
```
Multi-touch Attribution (last-touch, linear, time-decay, data-driven)
Media Mix Modeling (LightweightMMM: TV, radio, digital, OOH)
Causal Incrementality (geo holdout tests, PSM)
Budget Optimizer (constrained optimization: max revenue given budget)
Dashboard (channel performance, diminishing returns curves)
```

## 📊 Channel Attribution Results (before vs after)
| Channel | Attributed Revenue (before) | True Revenue (after) | Delta |
|---------|---------------------------|---------------------|-------|
| Paid Search | R$18M | R$14M | -22% (over-credited) |
| Social Ads | R$8M | R$12M | +50% (under-credited) |
| TV | R$6M | R$9M | +50% (MMM revealed impact) |
